# ZUI

**ZUI** is a modern GUI Toolkit designed to run natively on **Wayland**. It aims to provide a lightweight, performant, and flexible foundation for building graphical applications, while maintaining a clean and developer-friendly API.

ZUI is currently focused on the Wayland ecosystem and will be continuously developed toward **cross-platform support**, allowing applications built with ZUI to run across multiple desktop environments and operating systems.

> **Status:** Early Development
